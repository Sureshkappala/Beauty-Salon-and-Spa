# Glow & Grace — Luxury Beauty Salon & Spa Sanctuary 🌿✨

An ultra-luxurious, responsive website and client portal for **Glow & Grace**, a conscious botanical beauty salon and wellness retreat founded in 2014. Built with pure vanilla HTML5, CSS3, and JavaScript with zero external frameworks or heavy dependencies.

---

## 🌟 Key Highlights & Features

- **🌸 Holistic Sensory Design:** Soft blush, champagne gold, and warm ivory aesthetic paired with Playfair Display and Inter typography.
- **📱 100% Mobile & Tablet Optimized:**
  - Dynamic 3-bar animated hamburger menu with fluid drawer transition and zero horizontal overflow.
  - Responsive CSS Grid layouts across all screen viewports (320px to 1920px+).
  - Touch-friendly 44px+ touch targets and accessible ARIA attributes.
- **✨ Complete Sanctuary Experience (13+ Comprehensive Pages):**
  - **Homepage (`index.html`):** Hero showcase, signature rituals, testimonials, aesthetic preview.
  - **About (`about.html`):** Origin story, purity & hospital-grade sterilization protocols, 10-year milestones timeline, press accolades.
  - **Services Menu (`services.html`):** Filterable category grid, 3-step bespoke guest consultation ritual, complimentary sanctuary amenities.
  - **Specialty Service Pages:**
    - `hair-styling.html`: Hair health & texture diagnostic mapping, styling FAQs.
    - `skincare.html`: Transepidermal water loss assessment, botanical ampoules, facial FAQs.
    - `spa-treatments.html`: Artisanal scent library, restorative science benefits.
    - `bridal-makeup.html`: 6-month countdown roadmap, 16-hour camera endurance guarantee.
  - **Packages & Pricing (`packages.html`):** Group celebrations, private bridal suite buyouts, VIP membership benefits.
  - **Gallery (`gallery.html`):** Filterable visual showcase, before & after transformation spotlights, atmosphere vibe cards, full-screen lightbox modal.
  - **Service Details (`service-details.html`):** Step-by-step treatment journey, recommended ritual add-on pairings.
  - **Interactive Booking Flow (`booking.html` & `booking-confirmation.html`):** Real-time price calculation, dynamic time-slot selector, booking reference generator, printable confirmation slip.
  - **Contact & Concierge (`contact.html`):** Valet information, ADA accessibility, private VIP rear entrance, sanctuary etiquette policies.
- **🛡️ Dedicated Dashboards:**
  - **User Client Portal (`user-dashboard.html`):** Authenticated VIP credentials card, active appointment tracking, loyalty balance, treatment history.
  - **Admin Sanctuary Control (`admin-dashboard.html`):** Revenue charts, appointment management, staff assignment modal, treatment status controls.

## 🚀 Live GitHub Pages Deployment Guide

This project is 100% static and requires zero build steps or compilation.

To enable GitHub Pages for this repository:
1. Navigate to **Settings** > **Pages** in this GitHub repository.
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Select branch: `main` (or `master`) and folder: `/ (root)`.
4. Click **Save**.
5. Your live website will be available at:
   `https://sureshkappala.github.io/Beauty-Salon-and-Spa/`
